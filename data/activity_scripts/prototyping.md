# Prototyping

Construir protótipos realistas o suficiente para testar com usuários, mas rápidos o suficiente para iterar.

## Principles

- **Fake it**: O que parece real é real o suficiente
- **Build just enough**: Apenas o necessário para testar hipóteses
- **Move fast**: Protótipo em 1 dia

## Workflow

### Phase 1: Define Scope

1. What hypotheses are we testing?
2. What flows/screens are critical?
3. What can be faked vs. built?

### Phase 2: Divide & Conquer

Split work among team members:
- Designer: Visual design & layout
- Writer: Copy & content
- Developer: Interactive elements

### Phase 3: Build

Create the prototype using preferred tool:
- Figma/Sketch for UI mockups
- InVision/Framer for interactive prototypes
- Code if necessary for fidelity

### Phase 4: Stitch Together

- Combine all pieces
- Test flow internally
- Polish rough edges

### Output

- Link to prototype
- Testing script/scenarios
- List of hypotheses to validate
