# How Might We (HMW)

Técnica de Design Thinking para reframear problemas como oportunidades através de perguntas abertas.

## Workflow

### Phase 1: Problem Framing

1. Review the challenge or problem statement
2. Identify key pain points and insights
3. Break down complex problems into smaller components

### Phase 2: Generate HMW Questions

Transform each problem/insight into "How might we..." questions.

**Good HMW questions are:**
- Broad enough to inspire creativity
- Narrow enough to be actionable
- Optimistic and possibility-focused
- Not suggesting a solution

**Format:**
```markdown
## HMW Questions

1. How might we [action] [subject] so that [benefit]?
2. How might we...
...
```

### Phase 3: Prioritization

- Group similar HMWs
- Vote on most promising opportunities
- Select 3-5 HMWs to explore further

### Output

Save the final list of prioritized HMW questions in markdown format.
