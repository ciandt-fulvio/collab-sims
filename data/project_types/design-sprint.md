# Design Sprint

Metodologia criada pelo Google Ventures para resolver grandes desafios através de design, prototipagem e testes com usuários.

## Stages

### 1. Understand (Segunda)
- Entender o problema profundamente
- Mapear o desafio
- Atividades: research, how-might-we

### 2. Diverge (Terça)
- Gerar múltiplas soluções
- Pensar fora da caixa
- Atividades: crazy-8s, solution-sketch

### 3. Decide (Quarta)
- Escolher melhor solução
- Criar storyboard
- Atividades: design-criteria, dot-voting

### 4. Prototype (Quinta)
- Criar protótipo realista
- Atividades: prototyping

### 5. Test (Sexta)
- Testar com usuários reais
- Validar hipóteses
- Atividades: user-testing

## Recommended Agents

- facilitator
- researcher
- designer
- developer
