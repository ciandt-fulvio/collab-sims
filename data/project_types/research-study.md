# Research Study

Metodologia de pesquisa para coletar insights profundos sobre usuários, comportamentos e necessidades.

## Phases

### 1. Planning
- Definir objetivos de pesquisa
- Escolher metodologia
- Recrutar participantes

### 2. Data Collection
- Conduzir entrevistas
- Observar comportamentos
- Coletar dados quantitativos

### 3. Analysis
- Analisar dados qualitativos
- Identificar padrões
- Gerar insights

### 4. Synthesis
- Criar deliverables
- Apresentar findings
- Recomendar next steps

## Recommended Agents

- researcher
- facilitator
- analyst
